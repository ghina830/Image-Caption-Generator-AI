# 🖼️ Image Caption Generator

## 📝 Project Overview
This project builds an automated **Image Caption Generator** that translates visual content into descriptive natural language sentences. It utilizes a combination of **Convolutional Neural Networks (CNN)** for image understanding and **Recurrent Neural Networks (RNN)** for language modeling.

## 🚀 Technical Architecture
* **Feature Extraction:** Used **InceptionV3** (pre-trained on ImageNet) to extract high-level visual features.
* **Sequence Modeling:** Implemented **LSTM (Long Short-Term Memory)** to generate coherent sentences based on image features.
* **Word Embeddings:** Applied **GloVe** (Global Vectors for Word Representation) to enhance the model's semantic understanding.
* **Evaluation:** The model was evaluated using **BLEU** and **METEOR** metrics to ensure linguistic accuracy.

## 🛠️ Tech Stack
* **Deep Learning:** Keras, TensorFlow.
* **NLP:** NLTK, GloVe Embeddings.
* **Data Processing:** OpenCV, Pandas, NumPy.
* **Dataset:** Flickr8K.
